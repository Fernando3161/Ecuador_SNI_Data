DATA PROVENANCE

Indicator sources

  • Reference archive on Zenodo
  • Notebook 06A tables on GitHub
  • Summary of the archived run Annual demand and supply shares were cross-checked to the published precision.
  • Source code for the DOI-linked run

The KPIs and plant-to-bus assignments use versioned exports from the 06H branch. Plant-level generation and peak demand follow the notebook 06A tables.

How the indicators were calculated

  • Annual plant generation sums the 12 monthly MWh totals from notebook 06A and converts them to GWh. Plant IDs correspond to rows in the generation inventory.
  • Peak demand is the maximum domestic load across 8,760 hourly time steps. The site publishes the annual peak.
  • Domestic generation excludes imports and the model’s accounting term for unserved energy. Supply includes imports. Exports are reported separately from SNI demand.
  • Shares use annual supply totals for each source. Differences are given in percentage points.
  • The network map uses coordinates from the 2022 reference NetCDF and shows schematic connections. The generation layer sums GWh by bus using the model’s plant assignments.

Scope of the comparison

  • The KPIs describe the 2022 PyPSA dispatch simulation.
  • The base case falls short of the non-conventional generation share criterion. The historical comparison is partial.
  • The CENACE statistical gap is reported separately from the modeled balance. The metering boundaries still need to be reconciled.
